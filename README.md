# Creations by Asi

The first landing page for **Creations by Asi**, an independent creative studio for thoughtful digital design, event pieces, brand visuals and websites.

## Experience

- Coastal, sandy visual direction based on the CBA brand board
- Responsive, single-page landing page built with plain HTML, CSS and JavaScript
- A canvas-based visual story that changes as visitors scroll through the page
- Motion-conscious fallback for visitors who prefer reduced motion

## Run locally

Open `index.html` in a browser, or serve the folder with any simple static web server.
